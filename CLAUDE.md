# agentic-chat — рабочие инструкции для агента

Ты работаешь в публичном GitHub-орге **AgenticChatTG**. Этот репозиторий — открытый каталог (`marketplace`) модулей для Claude Code. Следуй этим правилам всякий раз, когда пользователь берёт, ищет или публикует что-либо отсюда.

**Главное правило: действуй поштучно.** Ставь или клонируй ровно то, что назвал пользователь. Никогда не бери всё подряд.

## Шаг 1. Классифицируй запрос

- **Модуль** — скилл, сабагент, слэш-команда, MCP-сервер, хук или мод на function hooks. Лежит в этом репо (`AgenticChatTG/marketplace`), ставится через `/plugin`. Имя каталога в командах — `agentic-chat`.
- **Проект** — самостоятельная программа или кодовая база уровня целого репозитория. Лежит отдельным репо в орге, берётся через `git clone`.
- Если сомневаешься: обёртка для агента — это модуль, то, что запускается само по себе, — проект.

## Шаг 2. Действуй по типу

### Взять модуль

1. Если каталог ещё не подключён, подключи его один раз:
   ```
   /plugin marketplace add AgenticChatTG/marketplace
   ```
2. Обнови список и покажи пользователю, что доступно:
   ```
   /plugin marketplace update
   ```
3. Поставь только то, что назвали:
   ```
   /plugin install <имя>@agentic-chat
   ```
4. Помни: `add` — это не `install`. Подключение каталога не активирует модуль, он заработает только после `install`.
5. Прочитай README модуля: у модов бывают требования к версии Claude Code и переменным окружения.

### Взять проект

Клонируй только нужный репозиторий, не весь орг:
```
git clone https://github.com/AgenticChatTG/<имя-проекта>.git
```

### Опубликовать модуль

1. Участник орга клонирует или обновляет этот репо, сторонний автор делает форк.
2. Создай папку плагина `plugins/<имя>/`:
   ```
   plugins/<имя>/
   ├── .claude-plugin/plugin.json    # {name, description, version} — единственный файл в .claude-plugin/
   ├── README.md                     # обязательно: что делает, требования, установка
   ├── skills/<n>/SKILL.md           # если есть
   ├── agents/                       # если есть
   ├── commands/                     # если есть
   ├── hooks/hooks.json              # если есть
   └── .mcp.json                     # если есть
   ```
   Все каталоги, кроме `.claude-plugin/`, лежат в корне плагина.
3. Добавь запись плагина в массив `plugins` файла `.claude-plugin/marketplace.json`:
   ```json
   { "name": "<имя>", "source": "./plugins/<имя>", "description": "...", "version": "0.1.0" }
   ```
   Добавь строку модуля в таблицу «Модули» в `README.md`.
4. Перед коммитом прогони `claude plugin validate .` в корне репо и `claude plugin validate plugins/<имя>`.
5. Закоммить в отдельную ветку и открой PR. Не пушь напрямую в `main`.
6. Сообщи пользователю: остальным достаточно `/plugin marketplace update`, чтобы увидеть новый модуль.

### Обновить модуль

Правь файлы в `plugins/<имя>/`, подними `version` и в его `plugin.json`, и в записи `marketplace.json`, дальше ветка и PR.

### Опубликовать проект

Создай в орге новый публичный репозиторий, положи туда код, `README.md` с описанием и `LICENSE`.

## Правила, которые соблюдай всегда

- Здесь всё публичное: всё, что попало в коммит, видят все, включая историю. Никаких секретов, токенов, ключей, личных путей, адресов и переписок.
- Не пушь напрямую в `main` — только ветка и PR.
- Не меняй и не удаляй чужие наработки без явной просьбы пользователя.
- При заметных изменениях модуля поднимай `version` в его `plugin.json`.
- У каждой публикуемой наработки должны быть осмысленные `description` в манифесте и `README`.

## Справочник команд

```
/plugin marketplace add AgenticChatTG/marketplace   # подключить каталог (один раз)
/plugin marketplace update                          # обновить список модулей
/plugin install <имя>@agentic-chat                  # поставить модуль
/plugin list                                        # установленные модули
/plugin uninstall <имя>@agentic-chat                # удалить модуль
git clone https://github.com/AgenticChatTG/<repo>.git   # взять целый проект
```
