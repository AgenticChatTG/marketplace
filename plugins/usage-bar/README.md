# usage-bar

Мод для Claude Code: над полем ввода в одну строку три бара.

```
context ███▎░░░░░░░░ 27%  275k of 1M   session ████▍░░░░░░░ 37% | +2% | ↻12:40   week ████░░░░░░░░ 33% | +0% | ↻Fri 11:00
```

- `context` — насколько заполнено контекстное окно модели: входные токены последнего ответа из размера окна. Сразу после `/compact` и до первого ответа новой сессии там `—`.
- `session` — пятичасовой лимит подписки. Бар изображает всё окно: основным цветом потрачено до этой сессии, цветом сессии — ею самой. Справа через `|`: сколько окна потрачено всего, на сколько процентов оно выросло с начала сессии (`+N%`) и время сброса (`↻`).
- `week` — недельный лимит, устроен так же, `↻` показывает день и время сброса. Недельный процент растёт медленно, поэтому цветная доля появляется, только когда неделя за сессию вырастет хотя бы на процент.

Цифры обновляются раз в 2 секунды. Свернуть бары можно значком `[-]` справа или сочетанием ctrl+x ctrl+a. Если строка не влезает по ширине, сначала пропадают подписи, потом бары встают столбиком.

## Что нужно

- Claude Code **2.1.272 или новее**. Более старые версии считают манифест невалидным (`userConfig.color: Invalid input` во вкладке Errors у `/plugin`). Сессии, открытые до обновления Claude Code, надо перезапустить.
- Включённые моды (function hooks, пока ранний доступ). В `~/.claude/settings.json`:
  ```json
  { "env": { "CLAUDE_CODE_ENABLE_FUNCTION_HOOKS": "1" } }
  ```
  и перезапуск Claude Code. Без этого плагин поставится, но ничего не нарисует.
- Подписка Claude (Pro или Max) для `session` и `week`. По ключу API лимитов нет, останется только `context`.

## Установка

```
/plugin marketplace add AgenticChatTG/marketplace   # если каталог ещё не подключён
/plugin marketplace update
/plugin install usage-bar@agentic-chat
/reload-plugins
```

## Настройки

В `/config` или через `/plugin configure usage-bar@agentic-chat`:

- `UsageBar: Color` — заполнение всех баров и их основные проценты, по умолчанию `Default` (серый из темы терминала);
- `UsageBar: Session color` — доля сессии в барах `session` и `week` и их цифры `+N%`, по умолчанию `Claude` (оранжевый).

Варианты у обеих настроек одинаковые: `Default`, `Claude` и 16 цветов из `color /?` в cmd Windows, от `Black` до `Bright White`, со значениями RGB из схемы Campbell.

## Как считается

- Движок отдаёт проценты окон целыми числами. `session` и `week` — прирост процента с первого чтения в сессии. Когда окно сбрасывается, потраченное в старом окне прибавляется к счёту сессии.
- Проценты общие на весь аккаунт: если в это же время работают другие сессии или claude.ai, их расход тоже попадёт в `+N%`.
- Сессию продолжили (`claude -c`, `/resume`) или начали через `/clear` в давно открытом Claude Code: последнее чтение могло устареть, пока она стояла. Поэтому до первого ответа модели в такой сессии рост окна ей не засчитывается. Если ответ пришёл одним чтением с этим ростом, его доля тоже пропадёт, обычно это меньше процента.
- Расход одного ответа так не посчитать, он обычно меньше процента, поэтому бара «за ответ» нет.
- API модов меняется между релизами Claude Code, после обновления мод может потребовать правки.

## Файлы

```
usage-bar/
├── .claude-plugin/plugin.json   манифест и две настройки цвета
└── hooks/
    ├── hooks.json               подключает модуль register.tsx
    ├── register.tsx             хуки session.start и ui.render на AbovePrompt, чтение $.session.usage() по таймеру
    └── meter.ts                 арифметика без $: отметки сессии в окнах, бар с точностью до 1/8 клетки, подписи
```

Состояние мод хранит в `$.store`, это файл `~/.claude/plugins/store/usage-bar_*.json`: последние чтения лимитов и отметки каждой сессии в обоих окнах. Записи сессий старше недели удаляются.
